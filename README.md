# Sheryll Mendoza — Portfolio

Personal portfolio website of **Sheryll Mendoza**, Senior Full Stack Engineer based in Las Piñas City, Philippines.

**Live site:** https://YOUR-VERCEL-URL.vercel.app

## Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) (icons)
- [next-themes](https://github.com/pacocoursey/next-themes) (dark/light mode)

## Getting Started

```bash
# install dependencies
npm install

# run the dev server
npm run dev
```

Open http://localhost:3000 in your browser.

## Scripts

| Command         | Description                |
| --------------- | -------------------------- |
| `npm run dev`   | Start development server   |
| `npm run build` | Create production build    |
| `npm start`     | Serve the production build |
| `npm run lint`  | Lint the code              |

## Project Structure

```
app/            # Next.js app router (layout, page, global styles)
components/     # UI sections (Hero, Projects, Experience, Contact, ...)
lib/data.ts     # All site content (profile, projects, skills, experience)
```

## Deployment

Deployed on [Vercel](https://vercel.com) — every push to `main` triggers an automatic redeploy.

```bash
git add -A
git commit -m "your changes"
git push
```
